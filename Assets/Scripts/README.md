# Soul Knight Game Scripts

## Основные скрипты:

### GameManager
- Управление состоянием игры (Game Over, Game Win)
- Подсчет очков
- Управление здоровьем игрока
- Пауза/Продолжение игры

### LevelManager
- Управление уровнями (Лес, Снег, Вода)
- Создание порталов для перехода между уровнями
- Настройка заднего фона для каждого уровня

### MainMenu
- Главное меню с кнопками Start, Settings, Exit
- Анимации кнопок
- Настройки игры

### PlayerMovement
- Движение игрока (WASD/Стрелки)
- Прыжки (Space)
- Ограничение скорости

### PlayerAttack
- Стрельба (Space)
- Ближний бой (Enter)
- Создание пуль

### PlayerHealth
- Здоровье игрока
- Неуязвимость после получения урона
- Лечение

### Enemy
- ИИ врагов (патрулирование, преследование)
- Атака ближнего боя и дальнего боя
- Выпадение предметов после смерти

### Portal
- Порталы для перехода между уровнями
- Визуальные эффекты

### Bullet
- Пули игрока и врагов
- Обработка попаданий

### Coin
- Монеты, выпадающие из врагов
- Анимация сбора

### HealthPickup
- Аптечки, выпадающие из врагов
- Лечение игрока

### WeaponPickup
- Оружие, выпадающее из врагов
- Увеличение урона и скорости атаки

### DamageNumber
- Отображение чисел урона
- Анимация всплывающих чисел

## Как использовать:

1. Откройте Unity
2. Назначьте скрипты на соответствующие объекты
3. Настройте префабы в инспекторе
4. Запустите игру!

## Управление:
- WASD/Стрелки - Движение
- Space - Стрельба / Прыжок
- Enter - Ближний бой
- P - Пауза
